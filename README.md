Ingeniero en Informática enfocado en el **ciclo de vida completo del software**, infraestructura **Cloud** y seguridad aplicada. Diseño, despliego y opero arquitecturas en producción para **+1.000 usuarios**, con transición activa hacia **DevSecOps**.

Combino desarrollo backend sólido con **hardening**, automatización e **investigación de vulnerabilidades** — con reportes de impacto nacional escalados a través del **CSIRT** de Chile.

Asimismo, optimizo el ciclo de vida del software (SDLC) integrando herramientas de IA Generativa, aplicando estrictas políticas de **Data Loss Prevention (DLP)** y sanitización de contexto para garantizar la protección absoluta de secretos e información confidencial frente a modelos de terceros.

## 🚀 Proyectos Destacados

### 🛡️ Kyrios Grid Shield — *SOC SaaS Zero Trust* `en desarrollo`
Plataforma **SaaS de seguridad Zero Trust** (SOC) construida como monorepo y desplegada en **Azure**.
- **Arquitectura:** Microservicios: React (frontend) · FastAPI (gateway) · Node.js (microservicio de auth)
- **Auth avanzada:** JWT interno unificado sobre **Microsoft Entra ID (RS256)** + **Google OAuth**, más API Keys **M2M** con caché JWKS.
- **Features:** análisis de archivos, MFA TOTP, telemetría/DLP y gestión de integraciones.
- **Cloud:** Azure Static Web Apps + Container Apps.

`FastAPI` `React` `Node.js` `Azure` `Zero Trust` `OAuth2/OIDC`

<br>

### 🌐 [SINTEREC](https://sinterec.cl) — *Plataforma Sindicato CLARO Chile* `en producción`
App web full-stack para **+1.000 socios activos**.
- Arquitectura MVC desacoplada con **CI/CD** y despliegue continuo.
- Backend seguro: **JWT + bcrypt**, control de roles, rate limiting anti-DDoS.
- Migración productiva **PostgreSQL → MySQL/MariaDB** sin pérdida de datos.
- Endpoints de **telemetría** (métricas JSON) para monitoreo de latencia y estados HTTP.

`Node.js` `Express` `React/Redux` `MySQL` `Linux/cPanel` `CI/CD`

<br>

### ⚡ [IVS Energy](https://ivsenergy.cl) — *Web Corporativa & SEO Técnico* `en producción`
Sitio de una startup de ingeniería eléctrica, optimizado para captación orgánica.
- Reducción de **TTFB de 1.13s → <0.2s** migrando a **SSG con Next.js 14**.
- SEO técnico: **JSON-LD (Schema.org)**, sitemap dinámico y cluster geográfico por comunas.
- **Core Web Vitals en verde** + analítica de conversión (GA4 / Vercel Analytics).

`Next.js 14` `TypeScript` `Tailwind CSS` `Vercel`

<br>

### 🔋 AhorraLuz — *Capstone (aprobado con distinción)*
Plataforma de análisis de consumo energético con modelo predictivo.
- **Arquitectura:** MVT (Django)

- Ingeniería de características temporales y **modelo ML** de consumo.

`Django` `Python` `PostgreSQL` `ETL` `Power BI`

## 🔒 Security Engineering Snapshot

| Área | Herramientas y Prácticas |
| :--- | :--- |
| **Autenticación & Acceso** | JWT + bcrypt, OAuth2/OIDC, expiración de tokens, sesiones seguras, control de roles. |
| **Hardening Backend** | Cabeceras HTTP (CSP, HSTS, X-Frame-Options), rate limiting, validación de entradas, manejo seguro de errores. |
| **Testing de Red** | Análisis de tráfico con Nmap, Wireshark y mitmproxy (fingerprints JA3) en entornos controlados. |
| **Estándares** | Revisión de código bajo OWASP Top 10, CWE y CVE. |
| **Automatización** | Scripts en Python para análisis de logs, generación de alertas y apoyo a auditorías. |

> 🧭 **Enfoque:** prevención, observabilidad y reducción de la superficie de ataque.
